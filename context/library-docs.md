# Library Docs

- Stack: Swift 6.4.2 (`-strict-concurrency=complete`), SwiftPM, macOS 15+ & Linux CLI-only distribution.
- `apple/swift-argument-parser` (`1.8.2`): CLI subcommands, flags, async parsable commands.
- `swiftlang/swift-syntax` (`604.0.0`): `SwiftParser` + `SwiftSyntax` for AST symbol outline, definition lookup, and Swift source editing.
- `apple/swift-nio` (`2.105.0`): `NIOCore`/`NIOPosix`/`NIOHTTP1` non-blocking Unix domain socket IPC and webhook HTTP server.
- `apple/swift-crypto` (`5.1.1`): HMAC-SHA256 webhook verification, SHA-256 content hashes, AES-GCM encrypted Linux key vault.
- `apple/swift-log` (`1.17.0`) & `apple/swift-metrics` (`2.13.0`): Structured observability, token/latency counters.
- Apple System Frameworks: `FoundationModels` (`SystemLanguageModel.default` Local ~4K + `PrivateCloudComputeLanguageModel` ~32K & `quotaUsage`/`resetDate`/`limitIncreaseSuggestion`), `Security` (Keychain), `Virtualization` (`VZVirtualMachine` + VirtioFS + vsock), `SQLite3` (FTS5 memory store).
